# Скриншоты проектов

Клади сюда картинки для карточек в секции «Проекты».

Ожидаются файлы:

- `databaser.png` — скриншот Databaser
- `ide.png` — скриншот IDE для агентной разработки

Подключается в `content/site.ts` через поле `image` у проекта:

```ts
image: { src: "/projects/databaser.png", alt: "..." }
```

## Перед публикацией — обязательно

Скриншоты попадают в открытый доступ. Проверь, что на них НЕТ:

- реальных имён, email, телефонов, ссылок на профили;
- имён продакшн-баз, хостов, токенов;
- любых данных клиентов или сотрудников.

Лучший вариант — снять интерфейс на тестовой базе с выдуманными данными.
Если это невозможно — замазать все чувствительные поля перед сохранением.
